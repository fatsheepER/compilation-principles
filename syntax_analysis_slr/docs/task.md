# 实验 4：SLR(1) 分析方法

## 一、实验目的

1. 构造 SLR(1) 分析程序，利用它进行语法分析，判断给出的符号串是否为该文法识别的句子。
2. 通过对 SLR(1) 分析方法的实验，加深对 LR 系列分析方法的理解。

## 二、实验要求

对下列文法，用 SLR(1) 分析法对输入的符号串进行分析：

```text
S -> E
E -> E + T
E -> T
T -> T * F
T -> F
F -> (E)
F -> i
```

## 三、实验步骤

1. 实现总控程序，也可以称为驱动程序：对所有的 LR 分析器总控程序都是相同的。
2. 构建分析表：不同的文法分析表将不同，同一个文法采用的 LR 分析器不同时，分析表将不同，分析表又可以分为动作表（ACTION）和状态转换（GOTO）表两个部分，它们都可用二维数组表示。
3. 利用分析栈对输入串进行分析：分析栈包括文法符号栈和相应的状态栈，它们均是先进后出栈，分析器的动作就是由栈顶状态和当前输入符号查分析表所决定。
