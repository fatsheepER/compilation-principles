# 词法分析设计表

## 一、种别码分配规则

| 区间      | 含义              |
| ------- | --------------- |
| 0~99    | 标识符与常量          |
| 100~199 | 关键字             |
| 200~299 | 运算符             |
| 300~399 | 界限符/分隔符         |
| 900~999 | 特殊记号（EOF/ERROR） |

## 八、错误类型表

| 错误码    | 名称                 | 说明         | 恢复策略        |
| ------ | ------------------ | ---------- | ----------- |
| `E001` | INVALID_CHAR       | 出现非法字符     | 跳过当前字符，继续扫描 |
| `E002` | INVALID_IDENTIFIER | 非法标识符      | 跳过直到空白或分隔符  |
| `E003` | INVALID_NUMBER     | 非法数字形式     | 跳过直到空白或分隔符  |
| `E004` | UNCLOSED_CHAR      | 字符常量未闭合    | 跳过到下一个引号或行尾 |
| `E005` | UNCLOSED_STRING    | 字符串常量未闭合   | 跳过到下一个引号或行尾 |
| `E006` | UNCLOSED_COMMENT   | 注释未闭合      | 跳过到文件末尾并报错  |
| `E007` | UNKNOWN_OPERATOR   | 无法识别的运算符组合 | 跳过当前字符或当前组合 |
| `E008` | INVALID_ESCAPE     | 非法转义字符     | 跳过到下一个引号或行尾 |

## 九、其他规则约定

### 1. 注释规则

支持单行注释 `// ...`，也支持块注释 `/* ... */`。注释不生成 token，需要正确跳过同时维护行号、列号信息。若注释未闭合则生成错误信息。

### 2. 标识符规则

首字符可以为字母或下划线；后续字符可以为字母、数字或下划线。

### 3. 整数常量

应当支持如下形式的整数：

- 十进制：`123`
- 八进制：`077`
- 十六进制：`0x1f`，`0X1F` ，`0XaBCd`
