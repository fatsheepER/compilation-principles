# 编译原理第 1 次实验-词法分析流程图

## 总控流程图

描述了整个词法分析器的入口逻辑。完成初始化后循环读入字符，遇到空白符就跳过，然后根据字符类别进入到不同的子流程。识别出一个 token 后，从子流程返回并继续扫描，直到 EOF 为止。

```mermaid
flowchart TD
    A([开始]) --> B[初始化输入流, 行号列号, 各类表]
    B --> C[读取当前字符]
    C --> D{是否到达EOF}
    D -->|是| E[生成EOF记号]
    E --> F([结束])

    D -->|否| G{当前字符是否为空白符}
    G -->|是| H[跳过空白符并前进]
    H --> C

    G -->|否| I{当前字符类别}
    I -->|字母或下划线| J[进入标识符或关键字流程]
    I -->|数字| K[进入整数常量流程]
    I -->|单引号| L[进入字符常量流程]
    I -->|双引号| M[进入字符串常量流程]
    I -->|运算符或界符或斜杠| N[进入运算符界符注释流程]
    I -->|其他| O[报告非法字符错误]

    J --> P[输出一个token]
    K --> P
    L --> P
    M --> P
    N --> Q{该流程是否产生token}
    Q -->|是| P
    Q -->|否| C

    O --> R[跳过当前字符并恢复]
    R --> C

    P --> C
```

## 标识符/关键字子图

进入此流程时首字符已经确定是字母或下划线。先识别完整个标识符，然后查关键词表判定。

```mermaid
flowchart TD
    A([开始]) --> B[清空token串]
    B --> C[读取首字符并加入token]
    C --> D{下一字符是否为字母数字或下划线}
    D -->|是| E[读取下一字符并加入token]
    E --> D
    D -->|否| F{token串是否在关键字表中}
    F -->|是| G[生成关键字token]
    F -->|否| H[查找或插入标识符表]
    H --> I[生成标识符token, attr为表下标]
    G --> J([返回])
    I --> J
```

## 整数常量子图

首先判断首字符是否为 0，若不是则只能是十进制整数，否则进一步判断是八进制还是十六进制（或者就是整数 0）。任何数字结尾遇到字母或下划线（十六进制当然有一点点特别）就被视为非法后缀，报错。否则该数字已读完。

```mermaid
flowchart TD
    A([开始]) --> B[清空token串]
    B --> C{首字符是否为0}

    C -->|否| D[读取首字符并加入token]
    D --> E{下一字符是否为数字}
    E -->|是| F[读取并加入token]
    F --> E
    E -->|否| G{下一字符是否为字母或下划线}
    G -->|是| H[报告非法数字后缀错误]
    H --> I[跳过到空白符或分隔符]
    I --> J([返回错误])

    G -->|否| K[加入常量表]
    K --> L[生成十进制整数token]
    L --> M([返回])

    C -->|是| N[读取0并加入token]
    N --> O{下一字符是否为x或X}
    O -->|是| P[读取x或X并加入token]
    P --> Q{下一字符是否为十六进制数字}
    Q -->|否| R[报告十六进制常量错误]
    R --> I

    Q -->|是| S[读取并加入token]
    S --> T{下一字符是否为十六进制数字}
    T -->|是| S
    T -->|否| U{下一字符是否为字母或下划线}
    U -->|是| H
    U -->|否| V[加入常量表]
    V --> W[生成十六进制整数token]
    W --> M

    O -->|否| X{下一字符是否为0到7}
    X -->|是| Y[读取并加入token]
    Y --> Z{下一字符是否为0到7}
    Z -->|是| Y
    Z -->|否| AA{下一字符是否为8或9}
    AA -->|是| AB[报告八进制常量错误]
    AB --> I
    AA -->|否| AC{下一字符是否为字母或下划线}
    AC -->|是| H
    AC -->|否| AD[加入常量表]
    AD --> AE[生成八进制整数token]
    AE --> M

    X -->|否| AF{下一字符是否为8或9}
    AF -->|是| AB
    AF -->|否| AG[加入常量表]
    AG --> AH[生成整数0的token]
    AH --> M
```

## 运算符/界限符子图

对于界限符，直接生成 token；对于斜杠，转入斜杠与注释处理流程；否则尝试运算符匹配，采用最长匹配原则：优先尝试双字符运算符，若没有匹配的，再尝试单字符运算符，都不行就报错。

```mermaid
flowchart TD
    A([开始]) --> B{当前字符是否为界符}
    B -->|是| C[读取当前字符]
    C --> D[生成界符token]
    D --> E([返回])

    B -->|否| F{当前字符是否为斜杠}
    F -->|是| G[进入斜杠与注释处理流程]
    G --> E

    F -->|否| H{是否能匹配双字符运算符}
    H -->|是| I[读取两个字符]
    I --> J[生成双字符运算符token]
    J --> E

    H -->|否| K{是否能匹配单字符运算符}
    K -->|是| L[读取一个字符]
    L --> M[生成单字符运算符token]
    M --> E

    K -->|否| N[报告未知运算符错误]
    N --> O[跳过当前字符并恢复]
    O --> E
```

## 注释子图

如果后面是另一个斜杠，进入单行注释，一直跳过直到换行或 EOF；若后面是 `*`，则进入块注释处理，匹配 `*/`，若遇到 EOF 则报错注释未闭合；若后面是 `=`，则生成 `/=` 运算符 token；否则，该 token 就是除号。

```mermaid
flowchart TD
    A([开始, 当前字符为斜杠]) --> B{下一字符类型}

    B -->|星号| C[进入块注释]
    C --> D{是否到达EOF}
    D -->|是| E[报告注释未闭合错误]
    E --> F([返回])

    D -->|否| G{当前字符是否为星号}
    G -->|否| H[继续读取注释内容]
    H --> D

    G -->|是| I{下一字符是否为斜杠}
    I -->|是| J[块注释结束, 不生成token]
    J --> F
    I -->|否| H

    B -->|斜杠| K[进入单行注释]
    K --> L{是否遇到换行或EOF}
    L -->|否| M[继续跳过字符]
    M --> L
    L -->|是| N[单行注释结束, 不生成token]
    N --> F

    B -->|等号| O[读取两个字符]
    O --> P[生成除赋值运算符token]
    P --> F

    B -->|其他| Q[读取一个字符]
    Q --> R[生成除号token]
    R --> F
```

## 字符常量子图

此时已确定是单引号开头。遇到 EOF 或换行就报错字符常量未闭合；若是反斜杠可以在读一个字符判断是否为转义字符；否则应当只有一个普通字符，且接下来单引号应当闭合。

```mermaid
flowchart TD
    A([开始, 当前字符为单引号]) --> B[清空token串并读入开头单引号]
    B --> C{下一字符是否为EOF或换行}
    C -->|是| D[报告字符常量未闭合错误]
    D --> E([返回错误])

    C -->|否| F{下一字符是否为反斜杠}
    F -->|是| G[读取反斜杠]
    G --> H{下一字符是否为合法转义字符}
    H -->|否| I[报告非法转义字符错误]
    I --> E
    H -->|是| J[读取转义字符]

    F -->|否| K[读取一个普通字符]

    J --> L{下一字符是否为结束单引号}
    K --> L

    L -->|是| M[读取结束单引号]
    M --> N[加入常量表]
    N --> O[生成字符常量token]
    O --> P([返回])

    L -->|否| Q[报告字符常量未闭合错误]
    Q --> E
```

## 字符串常量子图

此时已确定是双引号开头。遇到 EOF 或换行报错未闭合；遇到结束双引号说明识别完成；遇到反斜杠开始判断是否构成合法转义字符；否则将普通字符加入 token，直到成功闭合。

```mermaid
flowchart TD
    A([开始, 当前字符为双引号]) --> B[清空token串并读入开头双引号]
    B --> C{下一字符类型}

    C -->|结束双引号| D[读取结束双引号]
    D --> E[加入常量表]
    E --> F[生成字符串常量token]
    F --> G([返回])

    C -->|EOF或换行| H[报告字符串未闭合错误]
    H --> I([返回错误])

    C -->|反斜杠| J[读取反斜杠]
    J --> K{下一字符是否为合法转义字符}
    K -->|否| L[报告非法转义字符错误]
    L --> I
    K -->|是| M[读取转义字符并加入token]
    M --> C

    C -->|普通字符| N[读取普通字符并加入token]
    N --> C
```
