# LL(1) 文法、FIRST/FOLLOW 集与预测分析表

本文档根据原始文法 `G[E]`，整理消除左递归后的 LL(1) 文法、各非终结符的 FIRST 集和 FOLLOW 集，以及最终用于预测分析程序的分析表 `M`。

## 1. 原始文法 G[E]

```text
E → E + T | T
T → T * F | F
F → ( E ) | i
```

该文法中 `E` 和 `T` 都存在直接左递归，因此不能直接用于 LL(1) 预测分析，需要先消除左递归。

## 2. 改造后的文法 G'[E]

消除左递归后得到：

```text
E  → T E'
E' → + T E' | ε
T  → F T'
T' → * F T' | ε
F  → ( E ) | i
```

为便于构造预测分析表，将产生式编号如下：

| 编号 | 产生式 |
| --- | --- |
| 1 | `E → T E'` |
| 2 | `E' → + T E'` |
| 3 | `E' → ε` |
| 4 | `T → F T'` |
| 5 | `T' → * F T'` |
| 6 | `T' → ε` |
| 7 | `F → ( E )` |
| 8 | `F → i` |

## 3. FIRST 集

| 非终结符 | FIRST 集 |
| --- | --- |
| `E` | `{ (, i }` |
| `E'` | `{ +, ε }` |
| `T` | `{ (, i }` |
| `T'` | `{ *, ε }` |
| `F` | `{ (, i }` |

## 4. FOLLOW 集

| 非终结符 | FOLLOW 集 |
| --- | --- |
| `E` | `{ ), # }` |
| `E'` | `{ ), # }` |
| `T` | `{ +, ), # }` |
| `T'` | `{ +, ), # }` |
| `F` | `{ *, +, ), # }` |

说明：

- `#` 表示输入结束符。本实验中输入表达式以分号 `;` 结束，进入预测分析前可将 `;` 归一化为 `#`。
- `E` 是开始符号，因此 `#` 属于 `FOLLOW(E)`。
- 由产生式 `F → ( E )` 可知，`)` 属于 `FOLLOW(E)`。

## 5. 预测分析表 M

终结符列按 `i`、`+`、`*`、`(`、`)`、`#` 排列。空白单元表示该入口没有可用产生式，预测分析程序查到空白单元时应报语法错误。

| 非终结符 | `i` | `+` | `*` | `(` | `)` | `#` |
| --- | --- | --- | --- | --- | --- | --- |
| `E` | `E → T E' (1)` |  |  | `E → T E' (1)` |  |  |
| `E'` |  | `E' → + T E' (2)` |  |  | `E' → ε (3)` | `E' → ε (3)` |
| `T` | `T → F T' (4)` |  |  | `T → F T' (4)` |  |  |
| `T'` |  | `T' → ε (6)` | `T' → * F T' (5)` |  | `T' → ε (6)` | `T' → ε (6)` |
| `F` | `F → i (8)` |  |  | `F → ( E ) (7)` |  |  |

## 6. 表项来源

预测分析表按以下规则构造：

1. 对每个产生式 `A → α`，若终结符 `a ∈ FIRST(α)`，则将 `A → α` 填入 `M[A, a]`。
2. 若 `ε ∈ FIRST(α)`，则对每个 `b ∈ FOLLOW(A)`，将 `A → ε` 填入 `M[A, b]`。

对应到本实验文法：

| 编号 | 产生式 | 填入的表项 |
| --- | --- | --- |
| 1 | `E → T E'` | `M[E, i]`，`M[E, (]` |
| 2 | `E' → + T E'` | `M[E', +]` |
| 3 | `E' → ε` | `M[E', )]`，`M[E', #]` |
| 4 | `T → F T'` | `M[T, i]`，`M[T, (]` |
| 5 | `T' → * F T'` | `M[T', *]` |
| 6 | `T' → ε` | `M[T', +]`，`M[T', )]`，`M[T', #]` |
| 7 | `F → ( E )` | `M[F, (]` |
| 8 | `F → i` | `M[F, i]` |

## 7. 终结符约定

预测分析表只识别以下终结符：

| 终结符 | 含义 |
| --- | --- |
| `i` | 操作数。可由词法分析阶段的单个无符号整数或 lexeme 为 `i` 的标识符归一化得到。 |
| `+` | 加法运算符 |
| `*` | 乘法运算符 |
| `(` | 左括号 |
| `)` | 右括号 |
| `#` | 输入结束符，由表达式末尾的 `;` 转换得到 |
