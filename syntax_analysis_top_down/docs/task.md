# 实验二：预测分析语法分析器

## 一、实验目的和要求

1. 用预测分析技术实现语法分析器。
2. 理解自顶向下语法分析方法。
3. 熟练掌握预测分析程序的构造方法。

---

## 二、实验内容

### 1. 原始文法

算术表达式的文法为 **G[E]**：

```text
E → E + T | T
T → T * F | F
F → (E) | i
```

### 2. 实验任务

使用预测分析法，按照文法 **G[E]** 对算术表达式进行语法分析，判断表达式是否正确。

表达式包括：

- 加法运算符：`+`
- 乘法运算符：`*`
- 括号：`(`、`)`
- 操作数：单个无符号整数或 `i`

---

## 三、实验步骤

1. 阅读课本相关章节，将上述算术表达式文法改造成 **LL(1) 文法**。
   - 消除左递归
   - 必要时提取左公因子
2. 设计预测分析表。
3. 按照教材第 63 页图 4.4 中的算法编写预测分析程序。
4. 上机调试程序。
5. 发现错误后，分析错误原因，并修改完善程序。

## 四、测试要求

1. 为降低难度，表达式中不含变量，只含：
   - 单个无符号整数
   - 或符号 `i`

   - 错误提示越详细越好。
3. 测试表达式建议事先放在文本文件中。
   - 一行存放一个表达式
   - 每个表达式以分号 `;` 结束
4. 语法分析程序的输出结果写入另一个文本文件中。
5. 选作功能：
   - 当判断表达式正确时，输出计算结果。

## 七、实验指导

### 1. 改造后的 LL(1) 文法

将原文法 **G[E]** 改造为 **G’[E]**：

```text
E  → T E'
E' → + T E' | ε
T  → F T'
T' → * F T' | ε
F  → ( E ) | i
```

### 2. 文法说明

原始文法中存在直接左递归：

```text
E → E + T | T
T → T * F | F
```

改造后：

- `E` 表示一个完整表达式。
- `E'` 表示表达式后续可能出现的 `+ T` 部分。
- `T` 表示一个项。
- `T'` 表示项后续可能出现的 `* F` 部分。
- `F` 表示因子，可以是括号表达式，也可以是操作数 `i`。

## 八、可整理到报告中的关键内容

### 1. 预测分析程序基本思想

预测分析程序使用一个分析栈和一个输入串进行匹配。

基本过程如下：

1. 将 `#` 和开始符号 `E` 压入分析栈。
2. 从输入串读取第一个符号作为当前输入符号。
3. 弹出栈顶符号 `X`。
4. 根据 `X` 的类型进行处理：
   - 如果 `X` 是终结符，则判断它是否与当前输入符号匹配。
   - 如果 `X` 是非终结符，则查预测分析表 `M[X, a]`。
   - 如果 `X` 是 `#`，则判断输入是否也结束。
5. 如果查表得到产生式，则将产生式右部逆序压入分析栈。
6. 重复上述过程，直到分析成功或发现错误。

---

### 2. 推荐的程序输入设计

输入文件示例：

```text
1;
i+i;
(i+i)*i;
((i+i)*i+i;
i+i+i+(*i/i);
```

---

### 3. 推荐的程序输出设计

输出文件示例：

```text
1;                正确
i+i;              正确
(i+i)*i;          正确
((i+i)*i+i;       错误：缺少右括号
i+i+i+(*i/i);     错误：运算符后不能直接出现 *
```

---

## 九、实现时需要注意的问题

1. 输入表达式以分号 `;` 结束，但预测分析程序内部通常可以将分号转换为结束符 `#`。
2. 如果支持整数，需要在词法预处理阶段将无符号整数统一转换为 `i`。
3. 如果严格按照指导文法，只支持 `+` 和 `*`。
4. 示例中出现了 `-` 和 `/`，若要支持它们，需要扩展文法和预测分析表。
5. 空产生式 `ε` 不需要压入分析栈。
6. 产生式右部入栈时必须逆序压入。
